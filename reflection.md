# Reflections
As a quick experiment, Claude created for me a little interactive webpage to help demonstrate algorithmic complexity attacks and the effects they can have if not properly protected against. It gave a decent explanation of the process, and I quite enjoyed the visual demonstrations of the hash table and graph showing execution time for the hash based on the number of buckets and if there was a forced filling of only one bucket causing a massive spike in hash time.

## Workflow
This HTML page was created via the Claude agent with a prompt to generate a one-page HTML project that demonstrated algorithmic complexity and how attackers can use it to drastically reduce performance in a target's code.
